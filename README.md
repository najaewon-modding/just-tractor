# Just Tractor

마인크래프트에 단 하나의 트랙터를 추가하는 간단한 NeoForge 모드입니다.

트랙터를 타고 농장을 돌아다니며 성장한 작물을 자동으로 수확하고 다시 심을 수 있습니다.

## 기능

### 트랙터 소환

트랙터는 전용 **트랙터 알(Tractor Spawn Egg)** 아이템을 사용하여 소환할 수 있습니다.

아이템을 사용하면 해당 위치에 트랙터 엔티티가 생성됩니다.

### 탑승 및 운전

플레이어는 트랙터에 탑승하여 직접 운전할 수 있습니다.

트랙터는 일반적인 이동 수단처럼 전진, 후진 및 방향 전환이 가능합니다.

### 자동 수확

트랙터가 완전히 성장한 작물을 지나가면 해당 작물을 자동으로 수확합니다.

아직 성장 중인 작물은 수확하지 않습니다.

### 자동 재식재

작물을 수확하면 얻은 아이템 중 재배에 필요한 아이템 하나를 사용하여 같은 위치에 즉시 작물을 다시 심습니다.

예를 들어 밀을 수확하면 밀 씨앗 하나를 다시 심고, 당근이나 감자는 수확한 당근 또는 감자 하나를 다시 사용합니다.

따라서 트랙터가 지나간 뒤에도 농지는 그대로 유지되며 작물이 다시 자라기 시작합니다.

### 수확물 회수

재식재에 사용된 아이템을 제외한 나머지 수확물은 트랙터가 회수합니다.

즉, 기본적인 동작은 다음과 같습니다.

`성장한 작물 감지 → 수확 → 재식재용 아이템 1개 사용 → 즉시 재식재 → 남은 아이템 회수`

## 목표

Just Tractor는 복잡한 농업 시스템이나 대규모 자동화 기능을 추가하기 위한 모드가 아닙니다.

단순히 마인크래프트 농사를 조금 더 편하고 재미있게 만들어 주는 **하나의 탈것, 트랙터**를 추가하는 것을 목표로 합니다.
