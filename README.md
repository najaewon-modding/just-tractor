# Just Tractor

마인크래프트에 직접 운전할 수 있는 간단한 트랙터와 탈부착형 농업 장치를 추가하는 NeoForge 모드입니다.

트랙터 자체는 별도의 농업 기능이 없는 기본 차량이며, 필요한 작업에 맞는 장치를 장착하여 기능을 추가할 수 있습니다.

## 기능

### 트랙터 설치

전용 **Tractor** 아이템을 블록 위에 사용하면 해당 위치에 트랙터가 설치됩니다.

설치된 트랙터는 플레이어가 직접 탑승하여 운전할 수 있으며, 회수하면 다시 Tractor 아이템으로 돌아갑니다.

### 탑승 및 운전

플레이어는 트랙터에 탑승하여 직접 운전할 수 있습니다.

트랙터는 일반적인 탈것처럼 전진, 후진 및 방향 전환이 가능합니다.

농업 장치를 장착하지 않은 트랙터는 작물을 수확하거나 땅을 경작하는 등의 작업을 하지 않는 기본 차량으로 동작합니다.

### 트랙터 인벤토리

트랙터에는 수확물 등을 보관할 수 있는 내부 인벤토리가 있습니다.

트랙터에 탑승한 상태에서 인벤토리를 열어 내부 저장 공간을 사용할 수 있습니다.

또한 트랙터에는 농업 장치를 장착하기 위한 전용 **Attachment 슬롯**이 하나 존재합니다.

한 번에 하나의 장치만 장착할 수 있으며, 장치를 교체하여 트랙터의 작업 기능을 변경할 수 있습니다.

## 장치

Just Tractor는 다음 세 가지 탈부착형 장치를 제공합니다.

### Harvester Attachment

완전히 성장한 작물을 자동으로 수확하고, 가능한 경우 같은 작물을 다시 심는 장치입니다.

Harvester Attachment를 장착한 트랙터가 농작물 위를 지나가면 해당 작물이 수확 대상인지 확인합니다.

Just Tractor는 기본적인 농작물 판정을 위해 `CropBlock`을 사용합니다.

즉, 블록이 `CropBlock` 또는 이를 상속한 블록인 경우에만 기본 자동 수확 대상으로 취급합니다.

완전히 성장한 작물만 수확하며 아직 성장 중인 작물은 그대로 둡니다.

작물을 수확한 뒤에는 실제 수확물 가운데 원래 작물을 다시 심을 수 있는 아이템을 찾습니다.

적절한 아이템이 있으면 하나를 재식재에 사용하고 나머지 수확물은 트랙터의 내부 인벤토리로 회수합니다.

예를 들어 바닐라 작물은 다음과 같이 동작합니다.

* 밀 → 밀 씨앗 1개를 사용하여 재식재
* 비트 → 비트 씨앗 1개를 사용하여 재식재
* 당근 → 당근 1개를 사용하여 재식재
* 감자 → 감자 1개를 사용하여 재식재

재식재할 수 있는 아이템을 찾지 못한 경우에는 작물을 다시 심지 않고 모든 수확물을 회수합니다.

### Tiller Attachment

경작 가능한 흙 블록을 경작지로 만드는 장치입니다.

Tiller Attachment를 장착한 트랙터가 경작 가능한 지면 위를 지나가면 해당 블록을 경작지로 변환하여 농사를 준비할 수 있도록 합니다.

### Planter Attachment

빈 경작지에 농작물을 자동으로 심는 장치입니다.

Planter Attachment를 장착한 트랙터가 비어 있는 경작지 위를 지나가면 심을 수 있는 농작물을 자동으로 식재합니다.

## 작물 호환성

Harvester Attachment는 특정 작물 목록을 직접 지정하는 대신 기본적으로 `CropBlock`을 기반으로 작물을 판정합니다.

따라서 다른 모드에서 추가된 작물도 `CropBlock`을 상속하여 구현되어 있다면 자동 수확 대상이 될 수 있습니다.

재식재 여부 역시 밀, 당근, 감자 등의 아이템을 하드코딩하지 않고 실제 수확 결과를 기준으로 판단하는 것을 목표로 합니다.

이를 통해 별도의 모드별 호환 코드를 최대한 사용하지 않고 다양한 농업 모드와 자연스럽게 동작하도록 설계합니다.

단, `CropBlock`을 사용하지 않는 특수한 재배 블록은 기본 자동 수확 대상에서 제외될 수 있습니다.

예를 들어 호박, 수박, 사탕수수, 선인장 등은 일반적인 밭작물과 다른 성장 구조를 사용하므로 Harvester Attachment의 기본 자동 수확 대상에 포함하지 않습니다.

## 업그레이드

트랙터에는 장치와 별도로 성능을 향상시키는 업그레이드가 존재합니다.

### Fortune

Harvester Attachment를 사용하여 작물을 수확할 때 Fortune 효과를 적용합니다.

최대 3단계까지 업그레이드할 수 있습니다.

### Speed

트랙터의 최대 이동 속도를 증가시킵니다.

최대 5단계까지 업그레이드할 수 있습니다.

## 목표

Just Tractor는 복잡한 완전 자동 농업 시스템을 추가하는 모드가 아닙니다.

마인크래프트의 기존 농사 방식을 유지하면서, 플레이어가 직접 트랙터를 운전하고 필요한 장치를 교체하여 넓은 농장을 조금 더 편하고 재미있게 관리할 수 있도록 하는 것을 목표로 합니다.
