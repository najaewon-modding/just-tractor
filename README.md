# Just Tractor

Minecraft에 직접 운전할 수 있는 트랙터와 탈부착형 농업 장치를 추가하는 NeoForge 모드입니다.

트랙터 자체는 기본 차량으로 사용하며, **Harvester**, **Tiller**, **Planter** 장치를 교체해 수확, 경작, 식재 기능을 선택할 수 있습니다.

## 지원 환경

| 항목 | 값 |
| --- | --- |
| Minecraft | `26.1.2` |
| NeoForge | `26.1.2.97` |

## 주요 기능

- 직접 운전하는 트랙터
- 27칸 내부 보관함
- 농업 장치 전용 슬롯 1칸
- 수확 / 경작 / 식재 장치 교체
- Fortune 최대 3단계
- Speed 최대 5단계
- 트랙터를 아이템으로 회수해 다른 장소에 다시 설치 가능

## 트랙터 사용

### 설치와 탑승

Tractor 아이템을 블록 위에 사용하면 해당 위치에 트랙터를 설치할 수 있습니다.

설치된 트랙터를 우클릭하면 탑승합니다. 탑승한 상태에서는 일반적인 이동 키로 전진, 후진, 방향 전환을 할 수 있습니다.

### 인벤토리와 장치 슬롯

트랙터에 탑승한 상태에서 인벤토리 키를 누르면 트랙터 인벤토리를 열 수 있습니다.

- 내부 보관함: 27칸
- Attachment 슬롯: 1칸

Attachment 슬롯에는 Harvester, Tiller, Planter 중 하나만 장착할 수 있습니다. 장치를 교체하면 트랙터의 농업 기능도 즉시 바뀝니다.

### 트랙터 회수

탑승자가 없는 트랙터를 플레이어가 공격하면 회수할 수 있습니다.

- 서바이벌: 짧은 시간 안에 4번 공격하면 회수
- 크리에이티브: 한 번 공격하면 즉시 회수

회수할 때 트랙터의 업그레이드 단계는 Tractor 아이템에 유지됩니다. 내부 보관함과 장착 중인 Attachment의 아이템은 주변에 떨어집니다.

## 농업 장치

### Harvester Attachment

완전히 성장한 일반 밭작물을 자동으로 수확합니다.

- 성장 중인 작물은 건드리지 않습니다.
- 수확 후 다시 심을 수 있는 작물은 수확물 하나를 사용해 자동으로 재식재합니다.
- 남은 수확물은 트랙터 내부 보관함으로 들어갑니다.
- 보관함에 들어가지 못한 아이템은 일반 아이템으로 떨어집니다.

밀, 비트, 당근, 감자 같은 일반 밭작물과 비슷한 방식으로 구현된 다른 모드의 작물도 동작할 수 있습니다.

호박, 수박, 사탕수수, 선인장처럼 일반적인 밭작물과 성장 방식이 다른 작물은 기본 수확 대상이 아닙니다.

### Tiller Attachment

트랙터가 지나가는 경작 가능한 땅을 자동으로 경작합니다.

단, 실제 농장으로 유지할 수 있도록 해당 위치에서 **수평 4블록 이내에 물이 있을 때만** 경작합니다.

비가 오는 것은 물 조건으로 인정하지 않습니다.

### Planter Attachment

빈 경작지에 운전자가 들고 있는 작물을 자동으로 심습니다.

1. 먼저 주 손의 아이템을 사용합니다.
2. 주 손으로 심을 수 없으면 보조 손의 아이템을 확인합니다.

식재에 성공하면 해당 손에서 아이템 1개를 소비합니다.

## 업그레이드

탑승자가 없는 트랙터를 **Shift + 우클릭**하면 업그레이드 화면을 열 수 있습니다.

### Fortune

Harvester Attachment로 작물을 수확할 때 Fortune 효과를 적용합니다.

| 목표 단계 | 비용 |
| ---: | --- |
| 1 | 청금석 32개 |
| 2 | 금 주괴 32개 |
| 3 | 다이아몬드 32개 |

최대 3단계까지 업그레이드할 수 있습니다.

### Speed

트랙터의 최대 전진 및 후진 속도를 증가시킵니다. 단계마다 기본 최대 속도가 10%씩 증가합니다.

| 목표 단계 | 비용 |
| ---: | --- |
| 1 | 철 주괴 64개 |
| 2 | 구리 주괴 64개 |
| 3 | 레드스톤 가루 64개 |
| 4 | 금 주괴 64개 |
| 5 | 다이아몬드 64개 |

최대 5단계까지 업그레이드할 수 있습니다.

## 현재 아이템 획득 방법

현재 버전에는 Tractor와 세 Attachment의 조합법이 제공되지 않습니다. 관리자 명령어 등으로 아이템을 지급하여 사용할 수 있습니다.

```text
/give @s njw_just_tractor:tractor
/give @s njw_just_tractor:harvester_attachment
/give @s njw_just_tractor:tiller_attachment
/give @s njw_just_tractor:planter_attachment
```

따라서 현재 상태에서는 일반 서바이벌 진행만으로 모든 기능을 획득할 수 있는 완성된 제작 루트는 없습니다.

## 설치

1. Minecraft `26.1.2`와 NeoForge `26.1.2.97`을 설치합니다.
2. Just Tractor JAR 파일을 서버와 클라이언트의 `mods` 폴더에 넣습니다.
3. Minecraft 또는 서버를 실행합니다.
