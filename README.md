# Just Tractor

마인크래프트에 하나의 간단한 트랙터를 추가하는 NeoForge 모드입니다.

트랙터를 직접 운전하며 농장을 돌아다니면 완전히 성장한 작물을 자동으로 수확하고, 가능한 경우 같은 작물을 다시 심습니다.

## 기능

### 트랙터 소환

전용 **트랙터 알(Tractor Spawn Egg)** 아이템을 사용하여 트랙터를 소환할 수 있습니다.

트랙터 알을 사용하면 해당 위치에 트랙터 엔티티가 생성됩니다.

### 탑승 및 운전

플레이어는 트랙터에 탑승하여 직접 운전할 수 있습니다.

트랙터는 일반적인 탈것처럼 전진, 후진 및 방향 전환이 가능합니다.

### 자동 수확

트랙터가 농작물 위를 지나가면 해당 작물이 수확 대상인지 확인합니다.

Just Tractor는 농작물 판정을 위해 `CropBlock`을 사용합니다.

즉, 블록이 `CropBlock` 또는 이를 상속한 블록인 경우에만 농작물로 취급합니다.

따라서 일반적인 풀, 꽃, 덤불 등의 블록은 트랙터가 지나가더라도 수확하지 않습니다.

다른 모드에서 추가된 작물도 `CropBlock`을 기반으로 구현되어 있다면 동일한 수확 절차의 대상이 될 수 있습니다.

### 성장 상태 확인

`CropBlock`이라고 해서 무조건 수확하지는 않습니다.

트랙터는 해당 작물이 완전히 성장한 상태인지 먼저 확인합니다.

아직 성장 중인 작물은 그대로 두며, 완전히 성장한 작물만 수확합니다.

### 수확 및 재식재

완전히 성장한 `CropBlock`을 발견하면 해당 작물을 정상적으로 수확했을 때 생성되는 아이템을 계산합니다.

그 후 수확물 가운데 다음 조건을 만족하는 아이템이 있는지 확인합니다.

1. 현재 위치에 다시 심을 수 있어야 합니다.
2. 심었을 때 생성되는 작물이 수확하기 전의 원래 `CropBlock`과 동일해야 합니다.

두 조건을 모두 만족하는 아이템이 발견되면 해당 아이템 하나를 재식재에 사용합니다.

작물은 같은 위치에 초기 성장 상태로 다시 심어지며, 재식재에 사용하고 남은 아이템만 수확물로 회수합니다.

예를 들어 바닐라 작물은 다음과 같이 동작합니다.

* 밀 → 밀 씨앗 1개를 사용하여 재식재
* 비트 → 비트 씨앗 1개를 사용하여 재식재
* 당근 → 당근 1개를 사용하여 재식재
* 감자 → 감자 1개를 사용하여 재식재

### 재식재할 수 없는 작물

수확물 중에서 원래 작물을 다시 심을 수 있는 아이템을 찾지 못하더라도 수확 자체는 정상적으로 진행합니다.

이 경우에는 작물을 다시 심지 않고 모든 수확물을 회수합니다.

따라서 기본적인 수확 절차는 다음과 같습니다.

```text
트랙터가 블록 위를 지나감
        ↓
CropBlock인가?
        │
        ├─ 아니오 → 아무것도 하지 않음
        │
        └─ 예
            ↓
      완전히 성장했는가?
        │
        ├─ 아니오 → 아무것도 하지 않음
        │
        └─ 예
            ↓
       수확물 계산
            ↓
 원래 작물을 다시 심을 수 있는
      수확물이 존재하는가?
        │
        ├─ 예
        │   ↓
        │ 재식재용 아이템 1개 사용
        │   ↓
        │ 같은 위치에 초기 상태로 재식재
        │   ↓
        │ 나머지 아이템 회수
        │
        └─ 아니오
            ↓
        모든 아이템 회수
```

## 작물 호환성

Just Tractor는 특정 작물 목록을 직접 지정하지 않습니다.

대신 `CropBlock`을 기반으로 작물을 판정하기 때문에 다른 모드에서 추가된 작물도 `CropBlock`을 상속하여 구현되어 있다면 자동 수확 대상이 될 수 있습니다.

재식재 여부 역시 밀, 당근, 감자 등의 아이템을 하드코딩하지 않고 실제 수확 결과를 기준으로 판단하는 것을 목표로 합니다.

이를 통해 별도의 모드별 호환 코드를 최대한 사용하지 않고 다양한 농업 모드와 자연스럽게 동작하도록 설계합니다.

단, `CropBlock`을 사용하지 않는 특수한 재배 블록은 자동 수확 대상에서 제외됩니다.

예를 들어 호박, 수박, 사탕수수, 선인장 등은 일반적인 밭작물과 다른 성장 구조를 사용하므로 Just Tractor의 기본 자동 수확 대상에 포함하지 않습니다.

## 목표

Just Tractor는 복잡한 농업 자동화 시스템을 추가하는 모드가 아닙니다.

마인크래프트의 기존 농사 방식을 유지하면서, 직접 운전할 수 있는 하나의 트랙터를 통해 넓은 농장을 조금 더 편하고 재미있게 관리할 수 있도록 하는 것을 목표로 합니다.
